# omni-bot

面向熟人群聊场景的拟人化 Bot（Go 后端 + Svelte 5 WebUI），聚焦高准确率联想记忆、自然时序演化、细粒度情绪状态与谨慎的人格成长。

## 目录索引

- `AGENTS.md` — 仓库级工程规范、Go/Svelte 5 现代写法约束、索引维护与 Git 纪律。
- `.gitignore` — Go、Svelte 5 与本地运行数据/密钥的 Git 忽略规则。
- `go.mod` — Go 模块定义与最低工具链版本声明。
- `go.sum` — Go 模块依赖校验和锁定文件。
- `cmd/` — 可执行程序入口与独立聊天前端适配器目录。
- `docs/` — 系统设计文档与评测方案目录。
- `internal/` — Go 后端核心子系统与共享内部包目录。
- `scripts/` — 本地与 GitHub Actions 共享的统一 CI 脚本与目录索引校验工具。

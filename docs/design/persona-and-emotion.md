# 人格演化与动态情绪系统设计方案

> 目标是消除传统人设 Prompt 的静态死板与“表演感”，在不引入复杂脆弱规则机的前提下，通过**第一人称主体叙事 + 细粒度连续情绪体验 + 与记忆一体的极简慢成长**，让 Bot 呈现真实可信的动态生命力。

## 1. 人格三层结构与演化机制

依据心理学对人格组成的三元划分，将人格清晰解耦为**冻结锚石**、**底层动力参数**与**记忆驱动的慢变习惯**三层：

| 人格维度 | 心理学含义 | 系统载体与表现形式 | 演化策略 |
| :--- | :--- | :--- | :--- |
| **自我观念与信念** | 自我认知、核心价值观、主导观念（如何看待自己与世界） | 静态第一人称自述文本 | **绝对冻结（只读）**。任何后台任务无权修改，同时作为性格演化的价值锚点，防止群友诱导洗脑与身份崩塌。 |
| **气质 (Temperament)** | 偏先天的神经动力特征（反应快慢、情绪烈度、恢复节奏） | **PAD 情绪系统的底层动力学参数**（静息基线、敏感度、消退半衰期） | **全自动极微幅漂移**。不依赖 LLM，仅在周期 Dreaming 中用带硬上下界钳制的 EMA 数学公式对基线做极小步长环境适应，保证绝不发散。 |
| **性格 (Character)** | 后天社会生活中形成的态度与行为习惯 | **定长原子化第一人称条目清单**（硬上限 8~12 条） | **全自动、强克制、与记忆一体**。通过低频单次强模型反思直接从记忆层沉淀中做极小原子增量调整。 |

### 1.1 为什么采用「原子条目 + 周期性单次强模型反思」而非复杂证据状态机

* **零额外平行结构**：不单独建造 `trait_evidence` 观察表与跨天聚类规则机。记忆层自身维护的 `t_event`、`last_recalled`、`recall_count` 与 `strength` 本身就是最干净的长期沉淀过滤器——偶发玩梗进不了高强度前列，只有跨越时间、反复被唤起的真实互动模式才会留下。
* **杜绝反复改写散文的“传话筒漂移”**：如果每次 Dreaming 都重写整段性格散文，多轮迭代后细节会迅速流失并退化为空洞形容词。改为**上限 8~12 条原子条目**后，每次低频反思（例如按 Bot 互动节奏每 3~7 天或每积累一定量高强度记忆）用强推理模型审视：
  1. 冻结的《自我观念与信念》；
  2. 当前性格条目清单；
  3. 记忆库近期沉淀的高强度记忆（附带 `[事发时间 ~ 最近召回时间, 召回次数]`）。
* **极克制原子操作**：模型默认优先输出 `NO_CHANGE`；仅当高强度记忆中反复出现明确的长期习惯或态度形成时，才允许执行至多 1~2 条原子操作（`ADD` / `UPDATE` / `DROP`，满上限必须淘汰旧条目）。未被触碰的条目一字不改，每次变更自动留存不可变版本快照以便审计。
* **天然兼容前缀缓存**：性格层以天/周为周期极低频变化，且受条目数硬上限约束，不会膨胀上下文，也不破坏日常多轮对话的 System Prompt 前缀缓存。

### 1.2 气质参数的极简数学演化

气质直接编码为情绪引擎的初始先天配置：
* 静息基线 $(P_0, A_0, D_0)$
* 三轴刺激敏感度 $(\eta_P, \eta_A, \eta_D)$
* 回归半衰期 $(\tau_P, \tau_A, \tau_D)$

周期 Dreaming 结算时，仅对静息基线执行带包络钳制的极小步长平滑更新（例如每次最多向近期平均状态靠拢 `alpha = 0.02`，且严格限制在先天初值 `±0.15` 范围内），零 LLM 成本，绝对稳定。

## 2. 动态情绪系统（三维 PAD + 细粒度内在感受）

### 2.1 三维连续状态空间

维护一个连续三维情感状态向量 $(P, A, D) \in [-1.0, +1.0]^3$（不考虑多群隔离，单状态连续演进）：

* **$P$ (Pleasure，愉悦度)**：受用、轻快、开心 $\leftrightarrow$ 不爽、委屈、扫兴
* **$A$ (Arousal，激活度)**：精神充沛、紧绷、上头 $\leftrightarrow$ 犯困、发沉、倦怠松弛
* **$D$ (Dominance，掌控感)**：占上风、有底气、拿捏局面 $\leftrightarrow$ 吃瘪、被架住、被动防御

$D$ 维度在熟人群聊中尤为关键：同样是负向高激活（$P < 0, A > 0$），高 $D$ 对应“燥意与不耐烦”，低 $D$ 则对应“被戳中痛点或被起哄架住后的窘迫与不服气”。

### 2.2 零延迟 System 1 驱动与动力学

1. **并行顺风车判定**：在现有 System 1（`Gemini Decisions API /v1beta/decisions`）单次前向传播请求中，并行挂载 $(P, A, D)$ 三维刺激变化量评估（`0` 输出 Token，几乎 `0` 额外延迟），使 Bot 的情绪评估天然结合 `<persona>` 与当前对话脉络；即使当轮未发言，旁观群内氛围同样可微弱推动情绪演进。
2. **时间回落 + 阻尼叠加**：
   - 先依据距上次更新的时间差 $\Delta t$，按气质半衰期 $\tau$ 指数回归至静息基线 $(P_0, A_0, D_0)$；
   - 再将本次刺激 $(\delta P, \delta A, \delta D)$ 乘以气质敏感度 $\eta$ 阻尼叠加并约束在 $[-1, 1]^3$ 内，保证情绪平顺过渡、自然消退，不会因单句消息剧烈跳变。

### 2.3 设计红线：严禁代码硬限制与死板剧本指令

* **禁止任何代码层的死板行为干预**：不得根据 $(P, A, D)$ 数值在代码里硬压气泡上限、硬截断字数或手写 `if A < -0.3` 篡改接话阈值。
* **禁止剧本式做法指令**：不得向模型注入“控制在 10 字以内、不要用 `|||`、只发一个表情”这类动作命令——这会导致违和的机械表演。
* **禁止粗糙抽象标签**：不得只写“你现在很高兴/很生气”，避免触发大模型刻板戏剧化模板（滥用感叹号与夸张语气词）。

### 2.4 细粒度内在感受映射（Phenomenological Mapping）

情绪注入采用**高细粒度纯内在感受描述**：只刻画此刻的主观预期、精力质感、紧绷/松弛程度与心理张力，让模型顺着真实心境自然表达。

* **细粒度分区**：在 3D PAD 空间中预设高密度情绪原型质心（例如三轴三档去除原点共 **26 个基础原型**，可进一步细化至 30+ 个精细坐标点），再按距原点的径向模长 $r$ 叠加程度层次（隐约 / 明显 / 强烈），或对边界点做最近双原型融合，形成 70+ 种细腻心境梯度。
* **原点中性区**：当状态处于基线附近死区时，**不注入任何情绪块**，保持最松弛的日常底色。
* **单次 Run 固定注入且同步喂给 System 1 与 System 2**：
  - 将当前映射出的第一人称 `<inner_feeling>` 附入 **System 1** 输入：让 Decisions API 自己结合此刻是“精力充沛、跃跃欲试”还是“发沉犯懒、提不起劲”自然产出接话概率，彻底免除硬编码阈值偏置；
  - 将同一份 `<inner_feeling>` 固定挂载在 **System 2** 本轮动态上下文中（单次 Run 多步工具调用期间恒定不变，且置于动态区不破坏 System Prompt 前缀缓存）。

**感受表述示例（第一人称内在体验）**：
* 高 $P$ / 高 $A$ / 中高 $D$（期待・跃跃欲试）：`此刻我心里对接下来会展开的事隐约泛起一点期待，思路转得很快，整个人精力挺足。`
* 高 $P$ / 中高 $A$ / 极高 $D$（得意・拿捏）：`我觉得眼前这局自己明显占着上风，心里浮起一点藏不住的轻快和自得，既松弛又有底气。`
* 负 $P$ / 高 $A$ / 极低 $D$（窘迫・不服气）：`我感觉自己被架在了一个不太体面的位置上，心里有点发紧又带着一股别扭的燥意，本能地不太甘心就这么认栽。`
* 负 $P$ / 极低 $A$ / 中 $D$（倦怠・提不起劲）：`我觉得整个人有些发沉犯懒，注意力容易散掉，对眼前绕来绕去的琐事提不太起兴致，更偏向安安静静待着。`

## 3. 提示词人称与分层表现规范

为了消除“AI 助手照着人设说明书演戏”的抽离感，提示词按功能物理分层，严格区分人称视角：

| 区块 | 视角 | 编写铁律 |
| :--- | :--- | :--- |
| **系统运行协议与工具层** | 中性 / 第二人称 | 仅描述输出格式标记、工具调用规则与硬边界，与角色心智物理隔离，保持最高指令遵循精度。 |
| **自我观念与信念（冻结）** | **真第一人称（“我”）** | 用角色本人的原声口吻写看法、偏好与底线，兼作隐式语风锚定；**严禁上帝视角心理标签**（绝不写“我是个外冷内热、嘴硬心软的人”）。 |
| **性格（慢变原子条目）** | **真第一人称（“我”）** | 8~12 条具体可感的生活态度或相处习气短句，直接衔接自我观念。 |
| **当下情绪体验（单轮动态）** | **真第一人称（“我”）** | 细粒度内在主观体验描述，不含任何动作命令与格式限制。 |
| **历史记录中的自身发言** | 与第一人称自洽 | 使用 Bot 自身群昵称或 `[我(昵称)]` 标识历史回复，避免 `[你(Bot)]` 与第一人称人格产生视角割裂。 |

## 4. 待实测验证项

1. **Decisions API 情绪刺激打分探测**：在真实 `gemini-decision-1` 端点上对比 `score` 多档量表与成对 `noul` 概率评估 $(\delta P, \delta A, \delta D)$ 的校准度、单调性与延迟。
2. **第一人称 vs 第二人称盲测**：选取 10 段代表性群聊片段（闲聊、被调侃、严肃提问、深夜低电量、冷场），A/B 对比传统第二人称人设与本方案第一人称三层结构 + 细粒度感受的自然度与抗 AI 味表现。
3. **细粒度 PAD 词表迭代**：补全并打磨 26~30+ 个 3D 坐标质心的第一人称感受表述，通过多轮长对话模拟观测情绪轨迹分布，校准基线、敏感度与中性死区半径。
